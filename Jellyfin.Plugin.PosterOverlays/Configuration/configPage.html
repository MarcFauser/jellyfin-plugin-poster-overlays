Poster Overlays

Draws a badge onto the primary image so two entries of the same title can be told apart on the tile. The badge is not meant to survive: when a provider delivers a new cover it disappears, and the next run puts it back.

Operation

The last one is off by default and deliberately so: a local file is not replaced when a provider delivers a new cover, which defeats the upkeep loop.
Jellyfin delivers at 90; below that the badged copy is visibly worse than the original.

Categories

Each kind of entry picks its own preset and decides which badge kinds it may carry. A preset is a look; a category is a policy - which is what lets one preset serve several categories at once.

Series and seasons have no resolution of their own, so theirs is worked out from their episodes - including the copies that live in another resolution folder and only look like one entry in the client. Episodes are one file each and are best left to the switch below, which badges only where two rows carry the same episode and nothing else tells them apart.

Presets

Portrait and landscape, because one preset can serve both. Click a style to choose it. Where a category aggregates - series and seasons - the second row shows what a partly available badge looks like.

When something is only partly available

Series and seasons only. A series has no resolution of its own, so what it shows is aggregated from its episodes - and every episode has to agree, once several copies of one episode are collapsed to the best.
Worth keeping even beside the color: green and amber is exactly the pair that converges under the common red-green deficiency.

Rules

Comma separated "K" numbers. Measured width / 960, snapped to the nearest entry.
With 4, 1080p material gets none.

Exceptions

One item id per line.
One per line, as itemId = BADGE. An empty badge suppresses the edition badge for that item without excluding it entirely.

Backup and sharing

Presets are portable and worth sharing; the rest of the configuration is not. The exclusion list and the edition overrides are keyed by item id, which means something on this server and nothing anywhere else.

An import never overwrites: a preset whose id is already here and whose contents differ arrives as a copy with a numbered name. Press Save afterwards.

Run it for one item

The item menu in the web client is built from a fixed list and cannot be extended by a plugin, so this is the place to badge a single entry without waiting for the nightly task. The id is the one in the URL when the item is open. These buttons act at once and do not need Save.
