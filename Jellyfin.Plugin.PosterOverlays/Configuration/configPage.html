Poster Overlays

Draws a badge onto the primary image so two entries of the same film can be told apart on the tile. The badge is not meant to survive: when a provider delivers a new cover it disappears, and the next run puts it back.

Operation

Everything is worked out including the drawing, and then thrown away: no upload, no file, no recorded state. The task log says what it would have done. Leave this on for the first run.
This is what makes "Refresh metadata" in a film's own menu work as a manual trigger: the provider delivers a new cover and the badge is back seconds later. It also means the plugin writes during every library refresh.

Order

Top to bottom, and this is also the priority: when there are more badges than the maximum above, the ones at the bottom are the ones that go.

Look

All sizes are percentages, never pixels, so the same settings look the same on a 600x900 and on a 1000x1500 master.

50 gives fully rounded ends.

Resolution ladder

The K values a badge may show. A pixel width is divided by 960 and snapped to the nearest entry. Only 4K and 8K have standardised widths; everything above is extrapolation, which is why this is a setting.
With 4, 1080p material gets no badge.

Writing back

Run it for one item

The item menu in the web client is built from a fixed list and cannot be extended by a plugin, so this is the place to badge a single film without waiting for the nightly task. The id is the one in the URL when the item is open. These buttons act at once and do not need Save.
